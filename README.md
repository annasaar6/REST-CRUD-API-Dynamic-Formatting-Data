# Reflection

This assignment helped me gain a better understanding of RESTful APIs, even though I am still very new to the topic. I started by reading the document and watching the video, then recreated the program with the required changes. I added my favorite book to the hard-coded JSON data and changed all endpoints from `/books` to `/goodbooks`.

One challenge I faced was entering the code incorrectly early on. The errors became difficult to track down, and I eventually had to start over from the beginning. Although that was frustrating, it helped me pay closer attention to syntax and code structure. I also used AI assistance to help locate all instances of `/books` so I could make sure every endpoint was updated correctly.

What surprised me most was how RESTful APIs organize data using endpoints and HTTP methods such as GET, POST, PUT, and DELETE. Before this week, I did not really understand what a RESTful API was or how clients and servers communicate. I now have a better understanding of CRUD operations and JSON data, but I would like to learn more about how APIs connect to databases and how they are used in real-world applications.
